Routing accuracy improves with execution history

1,000 synthetic tasks across four families, five agents, seed 42. Every strategy sees the same task stream and the same random draw per task, so the oracle is a strict per-task upper bound. Capability-only is the identical router with the feedback loop switched off — it isolates what the execution history contributes. Curves are a 50-task rolling mean.

Which agent each strategy chose

The mechanism behind the gap. Capability-only never selects alpha or gamma even once — the generalist omni over-claims every family and wins on declared capability, so the two real specialists are never discovered. Horizon tries them, sees the outcomes, and converges on all four. ★ marks the genuinely best agent for a family.
